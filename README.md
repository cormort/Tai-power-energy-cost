單檔靜態儀錶板，資料來源為台電公司預、決算書與經濟部能源署電價費率審議資料。
線上版：<https://cormort.github.io/Tai-power-energy-cost/>

## 為什麼把 Chart.js 放在 repo 裡

原本從 jsDelivr 載入。實測把該網域封鎖後，inline script 在第一次繪圖就拋錯，
後續的明細表與試算器全部不會執行（表格 0 列、試算器全是 `--`）。政府機關內網、
含廣告封鎖器的瀏覽器都可能踩到，因此：

- `chart.umd.min.js` 與頁面同目錄，以 `<script src="./chart.umd.min.js">` 同步載入；
- 所有繪圖呼叫都經 `withChart()` 包裝，單張圖失敗只記錄 console；
- `hasChart()` 為 false 時顯示 `#chartFallbackNotice` 提示，**明細表與試算器照常運作**。

更新 Chart.js 時只需換掉該檔（版本寫在檔案開頭註解）。

## 資料更新流程

1. 新年度決算／預算書發布後，改 `index.html` 內 `const DATA`（燃料量價）、
   `const TARIFF`（電價與每度成本）、`const FIN`（淨利、累積虧損、長債、碳費預算）
   與 `const EXTRA`（購電結構、逐月氣價、發購電結構）四個資料物件。
2. **KPI 卡片與電價表都由資料自動算**（`renderKpis()` / `renderTariffTable()`）。
   HTML 裡仍留著一組靜態數字，但只是 JS 未執行時的備援，載入後會被覆寫 ——
   改資料時不必再手改 KPI，只要確認備援值沒有離譜到會誤導（無 JS 環境）。
   交叉驗證方法：改版前後各抓一次 `.kpi-card` 的 label/value/sub 做字串比對。
3. `DATA.operating_costs` 的「其他項目（維護費等）」是由
   `總成本 − 共同 6 項` 即時推算，只要補上該年度的 `總成本` 與各項金額即可。
4. 中油牌價 `EXTRA.cpc_gas_history` **只放實際觀測到的月份**。缺月不要補值：
   圖表以 `spanGaps:false` 斷線，並用 `gapBands` 外掛把缺口畫成灰色區塊。
5. `TARIFF` 的 `salesCost`（每度銷售成本）與 `salesProfit`（銷售盈餘）是決算書
   揭露值，無法由表內數字反推，因此獨立列欄、不由程式計算。

## 已知口徑註記（勿任意改掉）

- 燃料成本堆疊圖為**原料採購估算**（燃煤按 32.5 固定匯率換算），與決算書
  「自發電燃料成本」實績不同口徑（113 年差 215.39 億、114 年差 113.55 億），
  卡片下方有對帳說明，**不可與 KPI 直接相減**。
- 電價表「單位成本」欄已查明（`※1`）：決算書「5年來主要產品單位成本比較表」＝ 銷售成本 ÷ 供電量，
  110–112 複算 2.2784／3.6635／3.8624 與表列一致；**110→111 的 +60.8% 是真的**（銷售成本 +62.3%、
  供電量 +0.9%，主因 111 年燃煤 94.36→275.58 美元/噸）。真正的口徑變動在 **112 年**：決算書加註
  「自112年度起供電量含轉、直供電量」，分母變大 → 112 年以後與 110–111 不可直接比較
  （114 年剔除轉直供 59.69 億度後為 3.39 元/度，表列 3.31）。售電量已覆核（`※2`）。
- 電價表新增「同口徑單位成本」欄（`※3`）：112 年起決算書把轉、直供電量計入供電量，本欄改以
  銷售成本 ÷（供電量 − 轉直供）還原成 110–111 的基礎 → 112 **3.8901**、113 **3.4524**、114 **3.3925**
  （表列 3.8624／3.4110／3.3127）。115–116 是預算書「單位生產成本」，定義不同，該欄留「—」。
  `UNIT_COST` 逐筆存該年度決算書的銷售成本、供電量與轉直供，`sameBasisUnit(y)` 現算並自我檢查。
- **線損不是「發購電量 − 供電量」**。決算書「乙貳一」：供電量 ＝ 發購電量 − 儲能用電（114 年 2,584.13 − 46.99
  ＝ 2,537.14 億度）；線路損失量要再扣公司自用（5.86）、廠用電（4.81）、售電量**不含再生能源售電**（2,384.24）
  與轉直供（59.69），殘差 82.54 億度、線損率 3.19％（＝82.54 ÷ 2,584.13）。頁面上這段由 `POWER_FLOW`
  重算，殘差對不上會 `console.warn`。
- 售電量 2,390.57 億度（含再生能源售電）與 113 年 2,390.67 幾乎相同是實況；電費收入 932,799 百萬元 ÷
  239,057 百萬度 ＝ 3.9020 元/度，可回頭驗證「平均售電單價」。
- **碳費不可寫成「火力排放 × 費率」**。依《碳費收費辦法》第 5 條，碳費＝收費排放量×費率，
  收費排放量＝（年排放量−2.5 萬噸）×係數；第 8 條並允許生產電力事業扣除「提供電力消費之排放量」。
  115 年 13.1 億 ÷ 300 元/噸 ≈ 436.7 萬噸、116 年 3.77 億 ÷ 100 元/噸 ≈ 376.7 萬噸，
  僅約火力排放的 4.8%／4.3%。116 年金額大減的主因是**費率由一般費率 300 元改採優惠費率 100 元**，
  不是排放量腰斬。預算書未揭露收費排放量，頁面上的數字是由金額÷費率反推並標註。

## 版面容錯與分頁行為

- **主分頁**（`#viewTabs` + `[data-panel]`）把長頁面切成六個重點：關鍵指標分析／電價與成本／損益試算／
  購電與結構／財務與碳費／數據明細。桌機 sticky、手機不 sticky（避免吃掉 89px 視窗）。
  隱藏中的分頁**不預先建立圖表**（canvas 尺寸為 0 會畫成空白），切過去時才依 `PANELS` 清單補畫；
  列印時所有分頁自動展開。
- 三組分頁（走勢圖範圍／燃料別／明細表）都由 `wireTablist()` 綁定，不要各自加 onclick：
  `role="tablist"` / `role="tab"` / `aria-selected`、roving tabindex（Tab 鍵只停在選取項）、
  ←→↑↓ Home End 鍵盤切換、切換時內容 `swap-in` 淡入（`prefers-reduced-motion` 時關閉）、
  點同一顆不重繪、表格切換後 `scrollLeft` 歸零。
- 分頁狀態寫進 URL hash（`#table=gas&fuel=coal&scope=actual`）：重新整理、分享連結、上一頁／下一頁都會還原；
  載入時先還原狀態再渲染，避免先畫預設值再重繪一次。
- 手機（≤640px）：試算器改為「標題獨佔一列 + 滑桿／數值框」，滑桿不會被壓成 0 寬。
- 表格在 ≤720px 顯示「↔ 可左右滑動」提示與右側內陰影。
- `@media print` 會隱藏切換鈕與匯出鈕、卡片避免跨頁切斷，可直接列印或存 PDF。
